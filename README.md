# Biyomedikal AR-GE Konferans Radarı

Bu proje, biyomedikal alanı için konferans çağrılarını takip eden bir tarama ve izleme arayüzü geliştirmeyi hedefler.

Uyarı: Bu örnek veri, resmi siteden doğrulanmadan kullanılmamalıdır. Tüm kayıtlar demo amaçlıdır ve gerçek etkinlik tarihleri/başvurularının doğrulanması gerekir.

## Başlatma

```bash
npm install
npm run dev
```

Ardından http://localhost:3000 adresini açın.

## Aşama 1 kapsamı

- Ana sayfa arama, filtreler ve sıralama
- Konferans kartları ve yakın deadline vurgusu
- Detay sayfası ve takip listesi
- localStorage tabanlı takip sistemi
- .ics indirme desteği
